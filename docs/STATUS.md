# نَسَق 0.14.1

بدأت هذه النسخة من مصدر 0.13.0. رقم بناء أندرويد 17 ومعرّف التطبيق `com.yawmi.diabetes`.

- نجح بناء APK وفحص توقيعه. الشهادة مطابقة لشهادة ملف 0.13.0.
- نجحت اختبارات JUnit وعددها 110، ومنها رسم الويدجت على أندرويد API 35، واتجاه الأزرار، والاختصارات، واستمرار إعدادات التخصيص، وإخفاء البيانات بالقفل.
- نجح الفحص الساكن من دون أخطاء، مع تحذيرات توافق وأسلوب برمجي. نجحت 32 عملية تحقق إضافية من الحسابات والتشفير، وفحوص المصدر وخطوط تجوال.
- الصور في مجلد الوسائط من التطبيق باستخدام بيانات اختبار.
- تجربة التثبيت على هاتف فعلي وسلوك لانشر الهاتف والتنبيهات في الخلفية تتطلب اختبارات الجهاز الموضحة في [DEVICE_QA.md](DEVICE_QA.md).
