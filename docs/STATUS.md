# حالة النسخة 0.4.0

- APK أندرويد أصلي، مبني وموقع بنفس هوية النسخة 0.3.0 للتحديث فوقها.
- نجح assembleDebug وtestDebugUnitTest وlintDebug. لا توجد أخطاء lint؛ توجد تحذيرات توافق وإصدارات قديمة وبعض تحذيرات الترجمة البرمجية.
- 73 اختبار JUnit ناجح دون فشل أو تخط، منها تفاعل السحب والقوالب والتسجيل الكبير وخصوصية رسم الويدجت وأيام التذكير والتراجع.
- 32 فحصًا مستقلًا للمنطق والتشفير، و7864 فحص سلامة مصدر، و524 زوج ترجمة عربية وإنجليزية، وفحص خطوط تجوال الثلاثة.
- صور التصميم من رسم الواجهات الفعلية ببيانات تجريبية على Robolectric API 35.
- ملف GIF من 48 لقطة مختلفة للمياه والأرقام والأكواب، مصدرها الرسم الفعلي للمكونات.
- لا توجد تجربة على هاتف فعلي أو لانشر فعلي، ولا قياسات أداء GPU أو استهلاك بطارية. يلزم تجربة التنبيهات في الخلفية وإعادة التحجيم على الهاتف.
- البيانات الطبية السابقة محفوظة. لا توجد بيانات تجريبية تضاف إلى سجل المستخدم.
- التطبيق محلي وغير متصل بحساس السكر، ولا يغير الجرعات أو يحدد هدف سوائل طبيًا.
- راجع EXPERIENCE_0_4_AR.md للتخصيص والتذكيرات وحدود التحقق.
